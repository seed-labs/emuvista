# Examples

SEED Emulator examples use an `H**` directory prefix. Each example documents its
topology, generation, runtime behavior, and cleanup instructions.

| Example | Demonstrates |
| --- | --- |
| [H12: Domain Purchase and DNS Hosting](H12_domain_name_purchase/README.md) | Domain registration, DNS hosting, and simulated payment. |
| [H13: Browser and Agent](H13_browser_agent/README.md) | A browser agent running in a custom emulator container. |
| [H14: PKI HTTP-01 WebService](H14_pki_http01_web/README.md) | The built-in CA Service issuing an HTTPS WebService certificate with HTTP-01. |
| [H15: PKI DNS-01 Wildcard Certificate](H15_pki_dns01_wildcard/README.md) | A wildcard certificate issued through a TSIG-scoped RFC 2136 update. |
